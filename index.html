Cuestionario con nota de 0.0 a 5.0

Antes de empezar

20 preguntas. Cada respuesta correcta vale 0.25 (5 ÷ 20), y la nota es la suma de lo que acertes.

Lee con calma. Varias preguntas tienen trampa: un NOT, un > en vez de >=, un paréntesis que falta, un = NULL. Responder rápido es la forma más fácil de fallar.

Para las preguntas que cuentan filas, usa la tabla empleados (está siempre visible arriba de cada pregunta). Las preguntas salen en orden aleatorio.

Repaso rápido: tipos de sentencias SQL
  • DDL (estructura): CREATE, ALTER, DROP, TRUNCATE.
  • DML (datos): INSERT, UPDATE, DELETE.
  • DQL (consultar): SELECT. Algunos textos lo incluyen dentro de DML.
  • DCL (permisos): GRANT, REVOKE.
  • TCL (transacciones): COMMIT, ROLLBACK, SAVEPOINT.

Reglas útiles: AND se evalúa antes que OR; BETWEEN incluye los extremos; % son varias letras y _ es exactamente una; con NULL se usa IS NULL y COALESCE.
